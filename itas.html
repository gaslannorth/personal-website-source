ITAS: InSAR tools for slope-process analysis.

An integrated scientific environment for inspecting, preparing, and interpreting deformation observations with their geometry and terrain context intact.

Project overview

InSAR Toolbox for Analysis of Slopes

ITAS is developed as a transparent and reproducible toolbox that structures satellite line-of-sight observations for the analysis of unstable slopes, deformation patterns, and slope kinematics.

The scientific need

InSAR observations are powerful but geometrically constrained. Reliable interpretation requires explicit checks of data quality, acquisition geometry, terrain sensitivity, reference behavior, and uncertainty.

The product response

ITAS organizes those checks into connected project workflows so that each result can be traced back to its evidence, assumptions, and processing context.

Core workflow

Spatial deformation analysis

The spatial deformation analysis workflow supports project-based inspection of InSAR observations through acquisition geometry, terrain sensitivity, spatial relationships, and exportable analysis outputs.

01

Inspect

Review inputs, metadata, spatial relationships, and quality evidence.

02

Prepare

Align, filter, reference, and document the deformation datasets.

03

Assess

Evaluate LOS sensitivity, decomposition readiness, and constraints.

04

Interpret

Use terrain, direction, swath, and vector evidence to evaluate motion.

Capabilities

A connected analysis environment

Capabilities are designed as parts of an evidence chain, not isolated tools.

Data confidence

  • Input inspection and quality control
  • Filtering and reference correction
  • Project-level provenance

Geometry confidence

  • LOS geometry and terrain sensitivity
  • Ascending–descending decomposition readiness
  • Directional observability checks

Kinematic assessment

  • Standard decomposition
  • Terrain- and direction-constrained projection
  • Movement-direction LOS projection

Spatial interpretation

  • Swath-profile analysis
  • Vector-based assessment
  • Slope-context map review

Design principles

Scientific restraint is a feature

ITAS is designed to communicate readiness, limitations, and uncertainty rather than producing a result at any cost.

Transparent

Users can inspect what supports a result.

Reproducible

Projects preserve the path from input to interpretation.

Slope context

Topography and slope geometry remain central to the analysis.
